# Важливе та співпраця · Travelon

Сторінка для турагентів Тревелону: навчання й вебінари, семінари Travelon Talks, рекламні тури, автобуси, раннє бронювання, умови оплат і ануляцій, комісійна програма та додаткові послуги.

Відкривається з кнопки «Важливе та співпраця» в кабінеті агента на travelon.to.

**Сайт:** https://legree.github.io/vazhlyve/

## Що в репозиторії

| Файл | Що це |
|---|---|
| `index.html` | Уся сторінка в одному файлі: розмітка, стилі, скрипти, логотип, маскоти й патерн уже всередині |
| `README.md` | Цей опис |

Окремих картинок і бібліотек немає. Шрифт Nunito Sans підвантажується з Google Fonts.

## Як оновлювати дані

Відкрийте `index.html` на GitHub → значок олівця (Edit) → знайдіть блок `НАЛАШТУВАННЯ` на початку скрипта (Ctrl+F). Усе, що змінюється найчастіше, лежить там.

**Відео (`VIDEOS`)** — один рядок на відео:

```js
{ id: 'L9t1KX2Sn7Y', type: 'training', dur: '50:59', date: '28.09.2026', title: 'Назва відео' },
```

- `id` — 11 символів із посилання `youtube.com/watch?v=ID`
- `type` — `training` (навчання), `dest` (напрямок) або `hotel` (готель)
- `dur` — тривалість, `date` — дата публікації
- Нові відео додавайте на початок списку, бо порядок від нових до старих.

**Семінари (`SEMINARS`)** — місто, дата `дд.мм`, час, місце, теми й посилання на реєстрацію. Порожні поля показуються як «уточнюється», а без посилання кнопка неактивна.

**Посилання (`LINKS`)** — куди веде кнопка «Забронювати» в рекламному турі.

**Автобуси (`BUSES`)** — країна, місто й маршрути у форматі `['Маршрут', 'Період', 'посилання на графік']`.

**Раннє бронювання (`EARLY`)** — дати початку й кінця періоду, з них рахується лічильник днів.

Решта (умови оплат, штрафи, комісія, послуги, рекламні тури) — звичайний текст у розмітці сторінки, його теж можна правити прямо в `index.html`.

## Як оновити сайт

1. **Add file → Upload files** → перетягнути новий `index.html` → **Commit changes**.
2. Через 1–2 хвилини сторінка оновиться. Якщо бачите стару версію — `Ctrl+Shift+R`.

GitHub Pages: **Settings → Pages → Branch: `main` / `(root)`**.

## Стиль

Брендбук Travelon і UI Kit з Figma («01 - Travelon Web»):

- шрифт — Nunito Sans;
- акцент — `#FF7A5D`, натиснутий стан — `#F47358`, текст — `#171717`;
- іконки — набори дизайнера «Feather Icons» і «Specific Icons».

Сторінка адаптована під телефон: на вузьких екранах таблиці перетворюються на картки. Якщо в системі вимкнені анімації, вона показується без них.
